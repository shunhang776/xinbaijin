## 使用原则

- `00_总纲` 是最高层级原则；
- `01_专项方案` 解释技术设计、审查系统和整改策略；
- `02_制度与政策` 用于约束 Phase、例外、回滚和治理系统本身；
- `03_实施计划` 用于按天落地；
- `90_原始参考材料` 仅作为历史输入，不自动代表当前事实；
- 专项文档和总纲冲突时，先停止执行并建立治理变更任务，不得由开发 AI 自行解释冲突。
